## Features

- **Minimum query length**: Cling waits for 3 characters before searching instead of matching on the first keystroke. Set it in Settings > Search, `1` brings back the old behaviour

- **Dim status bar** fades the bottom bar for anyone who would rather not see it. Settings > Interface > Window

## Fixes

- Fixed a possible freeze while the results list was showing files from a drive that had stalled, caused by reading each row's size and date from the disk as the list drew and sorted

- Fixed a possible freeze when a script step timed out or failed to start

- Script steps no longer leave a temp folder behind on every run

## Improvements

- Size and date fill in immediately for files on the startup disk

- Results whose letters are scattered across a long path now rank below the ones that match the way you would type them

- Config files rank alongside everything else instead of being buried for living in a hidden folder

- Getting the extension wrong still finds the file: a query ending in `yml` can turn up the `.toml` you meant, and shortening one works too, so `ml` reaches `.toml`

- The status bar spells out the double tap that hides the toolbar rows, once you have picked a modifier for it
